# Move+ v1.0.4

PWA educativa, offline-first. Publicar o conteúdo deste ZIP na raiz do repositório GitHub Pages.

## Imagens
Substituir `assets/illustrations/ID.webp` mantendo o mesmo nome. Consultar `CATALOGO_IMAGENS.csv`. IDs anteriores não foram renomeados. Incrementar a versão da cache em `sw.js` e `version.json` e no código ao publicar novas imagens.

## Aviso
Os exercícios são opções, não uma prescrição. Respeitar restrições clínicas e procurar avaliação perante sinais de alerta.

## Validação
Verificação de sintaxe e de referências locais automatizada; testar instalação, navegação e actualização em dispositivos reais antes de produção.
